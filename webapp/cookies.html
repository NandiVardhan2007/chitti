This site doesn't set tracking cookies or load third-party analytics or ad scripts — in keeping with the app's own privacy stance. Here's the whole picture.

What this site actually stores

Fonts

The Inter typeface is loaded from Google Fonts (fonts.googleapis.com / fonts.gstatic.com). Loading any web font this way can reveal your IP address to the font host — the same as any site embedding a Google Font. We state it plainly rather than omit it.
