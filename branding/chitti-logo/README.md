# Chitti logo assets

Brand: iQOO yellow #F0B31C, deep #B9860A, ink #050508.

## svg/
- chitti-icon-primary.svg: main app icon (rounded tile, shaded face)
- chitti-icon-flat.svg: flat version
- chitti-icon-inverse.svg: yellow tile, black face
- chitti-icon-mono.svg: black and white
- chitti-icon-store-square.svg: full-bleed square with no rounded corners. Use it for the iOS App Store and Google Play, because they apply their own mask.
- chitti-adaptive-foreground.svg: transparent face only, for the Android adaptive icon foreground. Use background colour #050508.

## png/
- png/chitti-icon-primary/: 16–1024 px (web favicon, PWA 192/512, in-app)
- png/chitti-icon-store-square/: 16–1024 px (iOS 180/167/152/120, Play Store 512, Android mipmaps 48/72/96/144/192)
- chitti-adaptive-foreground-432.png / -1024.png: Android adaptive foreground (432 = xxxhdpi)
- flat / inverse / mono: 192, 512, 1024 px
